## Интерфейс

После запуска приложения из корня проекта откройте http://localhost:5050/.
Go-сервер раздаёт `public/index.html`; сборка фронтенда и установка npm-пакетов не нужны.
В Docker файл интерфейса также включён в образ: пересоберите приложение командой `make todoapp-deploy`.

Доступны разделы «Задачи», «Пользователи», «Статистика»: создание, просмотр,
редактирование, удаление, выполнение задач, поиск и фильтры. Для первой задачи
сначала добавьте пользователя. В «Настройках» можно изменить адрес API.

Статистика сохраняет логику бэкенда: `from` ограничивает дату создания снизу,
`to` — дату выполнения сверху (исключительно). При выбранной конечной дате
невыполненные задачи не входят в выборку. Интерфейс включает весь выбранный
конечный день и переводит границы из часового пояса браузера в UTC.
API принимает даты `YYYY-MM-DD` и RFC3339.

Проверка Go-кода: `go test ./...`.
